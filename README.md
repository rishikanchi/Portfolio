# Personal Portfolio

A sophisticated, minimalist personal portfolio website showcasing work in AI, cognitive science, and software development.

## 🌐 Live Site: [rishikanchi.com](https://rishikanchi.com)

## 🛠️ Tech Stack

- **React 18** + **TypeScript** - Modern, type-safe component development
- **Vite** - Lightning-fast build tool with hot reload
- **Tailwind CSS** + **shadcn/ui** - Beautiful, consistent styling system
- **Framer Motion** - Production-ready animations and interactions
- **React Router** - Declarative client-side routing

## 🎨 Design Philosophy

This portfolio embodies a **"old money minimalistic classy"** aesthetic that prioritizes:

- **Sophisticated Simplicity** - Clean layouts without unnecessary clutter
- **Timeless Typography** - Playfair Display serif headings with Inter sans-serif body text
- **Warm Color Palette** - Cream backgrounds with carefully chosen accent colors
- **Subtle Interactions** - Meaningful hover states and smooth animations
- **Content-First Approach** - Design serves the content, not the other way around

## 🏗️ Architecture

```
src/
├── components/     # Reusable UI components
├── pages/         # Main application routes
├── hooks/         # Custom React hooks
├── lib/          # Utility functions
└── index.css     # Global styles & design system
```
